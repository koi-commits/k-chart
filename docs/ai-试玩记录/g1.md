# 第 1 局（不读规则页）
> 角色：完全不懂股票的新手。只看屏幕文字和图表做决定；第一次打开时弹出的规则窗口被直接关掉、不阅读。
> 格式：每回合 `看到 / 打算 / 为什么 / 困惑`。

## 回合 1
- 看到：4 只股票各有价格和"今日"涨跌；顶部有两条进度条（收益率目标 +20%、最大回撤上限 20%）；右边有"研究"和"下单"面板；下方三个没有标题的小图。新闻只有一句"新赛季开始"。
- 打算：先试试"研究"——不知道有什么用，但名字听起来像是帮我挑股票。把 3 个研究点都投在第一只（金樽酒业）上。
- 为什么：点数不用白不用；"投入越多误差越小"这句我看懂了，所以全投。
- 困惑：①"基准 +0.0% + 20"是什么基准？②"最大回撤"是什么意思？③"手"是什么单位？④"误差 ±18%"是估值的误差还是什么的误差？⑤下面三个小图没有名字，不知道看什么。
- 结果：研究后左侧出现"估值 ¥113.95 ±5%"和"现价较估值 -8.3%"。我理解为：这只股票"值"113.95，现在只卖 104.51，便宜了 8%，像打折。
- 打算：买入金樽酒业，半仓（4 手），然后结束回合。
- 为什么：有"打折"的就买；不敢满仓，怕判负。
- 困惑："±5%"我猜是估值可能偏差 5%，所以便宜 8% 应该还是便宜？不确定能不能这样算。
- 回合小结（弹窗）：赚了 ¥660.73，费用 ¥11.27；而没买的华岳地产涨了 +15.80%（错过了，有点后悔）。小结很清楚，我看懂了。"费用"应该就是手续费。
