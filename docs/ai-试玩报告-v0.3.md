# AI 新手试玩报告 v0.3：评分界面

> 版本：v0.3-playtest（评分系统：总分 = 季度分 + 终局分 − 回撤扣分，B 及以上过关）。
> 只写报告，**没有根据报告改任何代码**，`config.js` 的数值保持冻结，等你看过再决定。
> 上一份报告见 [`ai-试玩报告.md`](ai-试玩报告.md)（v0.1，旧胜利条件）。

## 1. 方法与局限（请先读这一节）

**做法**：用 Playwright 驱动游戏，由 AI 扮演"完全不懂股票的新手"玩了 2 局（每局 20 回合，每局都是全新浏览器配置，开局弹出的规则页**都认真读了**）。驱动方式同上次：我每回合只看驱动脚本返回的"屏幕上显示的文字"和我主动请求的截图，不读源码、state、config。

- 第 1 局"稳健型"：按研究估值买便宜、分散、留意回撤。
- 第 2 局"追涨型"：想一把冲到 B，倾向买最近涨得多的、重仓，用研究但不严格按估值。

**局限（请自行打折）**：
1. 我是这个游戏的开发者本人，扮演新手时无法真正忘掉内部知识（比如我知道回撤只增不减）。凡是我"自己推理出来"的东西，真实新手更难，所以**困惑点是下限**。
2. 只有 2 局，是定性观察，不是统计结论。研究 bot 的分布数据在 `simulate.js` 里。
3. **第 2 局的第 8–19 回合是"放弃式推进"**（只点"结束回合"，没有逐回合重新决策）。其中第 8–9 回合还是因为我误把同一条"买 4 手 + 结束回合"指令连发了三次（买单因没钱未成交），等于"死拿不动"。所以第 2 局只有第 1–7 回合是认真玩的；后半段我只是在观察"一个想放弃的新手"会看到什么。第 1 局第 17–19 回合也是只点结束。这些我在记录里都标了。
4. 我没有真的点"重新开始"来测试重开体验（只记录了当时"想点"）。

每回合的详细记录（看到什么 / 打算做什么 / 为什么 / 困惑）在：
[`ai-试玩记录-v0.3/g1.md`](ai-试玩记录-v0.3/g1.md)、[`g2.md`](ai-试玩记录-v0.3/g2.md)；两局导出的记录文件在 [`ai-试玩记录-v0.3/records/`](ai-试玩记录-v0.3/records/)（可直接喂给 `scripts/analyze-records.js`）。

## 2. 两局概览

| | 第 1 局（稳健型） | 第 2 局（追涨型） |
|---|---|---|
| 收益率 / 基准 | **−0.77% / −9.92%**（多赚 9.1 点） | **+64.06% / +6.68%**（多赚 57.4 点） |
| 最大回撤 | 18.28% | 35.08% |
| 季度分 | +7.1 / −4.0 / +11.9 / +10.2（合计 +25.2） | −2.0 / −4.0 / +15.0 / +15.0（合计 +24.0） |
| 终局分 | +2.3 | +14.3 |
| **回撤扣分** | **−19.9** | **−45.1** |
| 总分 / 等级 | **+7.5 / D** | **−6.7 / D** |
| 没有回撤扣分时的总分 | +27.4（C，差 B 线 1.6） | +38.4（B） |
| 回撤扣分占"正分"的比例 | 73% | 118% |
| 若最大回撤只有 10% 时的总分 | +19.9 | +30.9 |

**一句话**：两局我都"跑赢了基准"（一个多赚 9 点，一个多赚 57 点，一个甚至赚了 64%），**两局都是 D**。回撤扣分是两局最大的一项。

## 3. 重点问题逐项回答

### 3.1 能看懂顶部的总分、预估等级、本季度得分、"距下一等级还差多少"和等级尺吗？
**大体能，等级尺最好懂。**
- ✔ 等级尺（D|C|B|A|S 五段色条 + 白色标记线）一眼就懂："我现在在 D 区，要往右走到 B。"[截图](ai-试玩截图-v0.3/g1-t01-board.png)
- ✔ "距 C 还差 14.0 分"直观；季度四小格的得分（`1 +7.1`、`2 -4.0`）也直观。
- ⚠ "预估等级""当前总分"需要悬停 ⓘ 才知道是"如果现在结束"的得分。
- ⚠ **开局 0 分就显示"预估等级 D 未到过关线 B"**，像一上来就被判差评（第 1 局第 1 回合）。
- ⚠ "全局超额 +0.6 点"和"本季度相对基准 −1.9 点"并排出现，要想一下区别。
- ⚠ 单季度得分被封顶/封底时（`+15.0`、`−4.0`）只是数字不动，没有说"已封顶"。我在第 1 局第 13 回合、第 2 局第 13–15 回合都是自己发现的。
- ✘ "距下一等级还差多少"在分数很低时变成噪音：第 2 局 −55 分时写着"距 C 还差 69.0 分"（见 4.2）。

### 3.2 季度成绩单和结算页的分数构成，能看懂自己为什么得了这个等级吗？
**算式完全能看懂，但"为什么扣这么多"觉得不合理。**
- ✔ 每一行"构成"都写出了算式（`跑赢基础分 5 ＋ 超额 +6.86 点 × 1 = +6.86`、`最大回撤 18.28%，超过 5% 的部分 13.28 个百分点 × 1.5`），我对着数一遍就明白，这是整个评分界面最清楚的地方。触及上下限也有标注（"→ 触及下限 −4"）。
- ✔ 结算页"你最后一次研究的估值：第 17 回合研究，已过期；当时真实价值 90.72，估值误差 −1.9%"也好懂。
- ✘ 看懂"算式"≠看懂"为什么"。我能算出 7.1 − 4.0 + 11.9 + 10.2 + 2.3 − 19.9 = 7.5，但仍然无法接受"我比基准多赚 9 个点却是 D"。算式把"怎么得的"说清了，没有说"这个等级意味着什么、该怎么改"（见 4.3）。

### 3.3 回撤扣分是否让新手过度保守（例如不敢持仓）？
**有影响，但表现是"针对性减仓/想放弃"，不是普遍空仓；而且更突出的问题是它让人"无力回天"。**
- 第 1 局第 14 回合：重仓华岳地产浮亏 −26%，顶部写着"已扣 18.5 分"。我这回合研究点已用完、没法重新研究，**明知"便宜不该卖"，仍因为"每多 1% 回撤多扣 1.5 分"把 4800 股全卖了**，之后几个回合基本空仓/轻仓。我自己的记录写的是："理由不是它被高估，而是我不敢再被扣分。"卖出后华岳当周 +7.6%。
- 第 1 局第 7 回合：因为上一周"卖飞"一只上涨的股票，本季度从 +6 分掉到 −4 分，我下次更不敢按估值卖出。（这是"跑输基准扣分"的影响，不是回撤。）
- 第 2 局第 2 回合：第 1 周只亏 2.2%，却因为周中盘中回落一度 9.5%，立刻背上 **6.7 分**扣分，总分 −9.0；之后我"不想再满仓单一股票"。
- 第 2 局第 7 回合以后：总分 −22 → −55，"距 C 还差 69 分"，我最想做的是**点"重新开始"**；没有点是因为测试计划，不是因为想继续。这是比"保守"更严重的反应：直接想弃局。
- **没有出现的**：没有出现"全程空仓"或"不敢买任何东西"。我始终在按估值找机会，只是在回撤已经很深、分数已经很难看时变得想放弃。

### 3.4 拿到 C 或 D 时，界面是否给出"下一局可以怎么改进"的线索？
**没有。** 两局的结算都只有分数表，没有任何一句"你的主要扣分来自……""下次可以……"，也没有反事实（"若最大回撤控制在 10%，你的总分是 +X"）。我只能自己从表里看出"回撤扣分最大"，但不知道"怎么做才能让回撤小"（分散？减仓？止损？还是少买高波动的？）。见 4.3。

## 4. 困惑点与问题（按严重程度排序）

严重度：**严重**＝影响评分机制是否成立 / 玩家会得出错误结论；**高**＝让一类玩家卡住或放弃；**中**＝明显困惑但可摸索；**低**＝小瑕疵。

### 4.1 【严重·设计】回撤扣分权重过大且无下限：赚 +64% 也是 D，总分可以是 −55
- **现象**：
  - 第 2 局最终收益 **+64.06%**（基准 +6.68%，多赚 57 点），季度分 +24.0、终局分 +14.3，**回撤扣分 −45.1**，总分 **−6.7，D**。没有这一项它是 +38.4（B）。[结算截图](ai-试玩截图-v0.3/g2-t20-settlement.png)
  - 第 1 局比基准多赚 9.1 点、4 个季度中 3 个跑赢，回撤扣分 −19.9 吃掉了 73% 的正分，D。没有它是 +27.4，离 B 只差 1.6 分。[结算截图](ai-试玩截图-v0.3/g1-t20-settlement.png)
  - 第 2 局第 2 季度结束时总分 **−55.0**：季度分和终局分都有下限（−4、−20），**只有回撤扣分没有下限**（45.1 分）。[季度成绩单](ai-试玩截图-v0.3/g2-t10-quarter.png)
- **为什么这是问题**：
  1. 它让"赢"和"等级"脱钩。后半段我满分（第 3、4 季度各 +15），也没法把第 2 季度的回撤"补回来"，因为最大回撤只增不减。
  2. 它惩罚的是"持仓期间的波动"，包括**大盘下跌**：第 1 局第 3 季度大盘 −11%、我只跌 4.5%（跑赢 6.9 点），这个季度里我的最大回撤仍从 12.8% 扩大到 17.3%，回撤扣分从 11.7 涨到 18.5，**多扣 6.8 分**。我写的原话是："明明是大盘跌 11% 我只跌 4.5%，还是被罚了。"
  3. 盘中回落也计入：第 2 局第 1 周只亏 2.2%，周中回落到 9.5%，立刻扣 6.7 分。第 1 周就是 −9.0 分。[截图](ai-试玩截图-v0.3/g2-t02-top.png)
  4. 对真人偏严：阈值 5%、每点 1.5 分，AI 新手这两局的回撤是 18% 和 35%；研究 bot 的平均最大回撤是 9.3%，已经要扣约 6 分。
- **建议（供你决定，我没改）**：给回撤扣分加上限（或递减斜率）；或把阈值放宽到真人更常见的区间；或让扣分与"相对基准的回撤"挂钩，避免大盘整体下跌时惩罚过度；至少在界面上把"最大回撤是盘中最低点、只增不减"说清。

### 4.2 【严重·体验】分数一旦深度为负，"距下一等级还差 X 分"变成嘲讽，玩家自己"判死"并想弃局
- **现象**：界面按要求**没有**"已无法过关"提示，但数字本身就说明了一切。
  - 第 1 局第 10 回合（Q2 结束）：总分 −9.3，我心算"剩下两个季度最多各 15 分，B（29 分）已经够不到"，目标降级成"至少 C"。
  - 第 2 局第 7 回合：总分 −22.4，"距 C 还差 36.4 分"；第 9 回合 −47.9，"距 C 还差 61.9 分"；Q2 结束 −55.0，"距 C 还差 69.0 分"。我的记录写的是："这时顶部的'距下一等级还差多少'不再是激励，而是嘲讽""我此刻最想做的事是点重新开始"。
- **影响**：这是上一轮你担心的"提前判死"问题的**主观版本**：`simulate.js` 里的"提前判死"指标是 0%（因为单季度和终局上限很大），但玩家看的不是上界，而是"当前离线还差多少分"。回撤扣分又只增不减，所以分数掉下去几乎回不来，等于隐性判死。
- **建议**：分数远低于 C 时不要显示"距 C 还差 69 分"这种数字（换成"本局最高还能到 X"或隐藏）；给"回撤扣分"一个下限（见 4.1）；或在深度为负时给一个"本局目标：把总分提到 0 以上 / 保住后面季度满分"的小目标。

### 4.3 【高】C/D 时没有任何"下一局怎么改进"的线索
- **现象**：两局的结算都只有分数表。我作为新手，想要的是：①一句话告诉我最大的扣分项（"回撤扣分 −45.1 是你最大的丢分项，占……"）；②告诉我能怎么避免（分散、减仓、止损）；③反事实（"若最大回撤只有 10%，总分 +30.9，可达 B"）。这些都没有。[结算截图](ai-试玩截图-v0.3/g1-t20-settlement.png)
- **建议**：结算页（以及季度成绩单）加一行"最大丢分项 + 一句通用建议"，数值全部由已有数据算出，不需要新规则；复盘页已有"真实价值 vs 价格"，可以补一张"你的总资产曲线 + 最大回撤发生的区间"。

### 4.4 【高】"跑赢基准才加分、跑输就扣分"与绝对收益脱节：赚钱可以是负分，亏钱可以是正分
- **现象**：
  - 第 2 局第 1 季度：账户 **+4.58%**，基准 +6.54%，超额 −1.96，季度分 −2.0；总分 **−9.2**。"赚钱 = 负分"。[截图](ai-试玩截图-v0.3/g2-t05-quarter.png)
  - 第 1 局第 2 回合：账户 **−5.2%**，基准 −5.8%，顶部总分 **+5.4**。"亏钱 = 加分"，我靠把几个数拼起来才懂（超额 +0.6 → 基础分 5 + 0.6）。
  - 第 1 局第 2 季度：我赚了 +7.33%，基准 +13.05%，得 −4.0。
- **影响**：规则页写了"高于基准就得 5 分"，但对不熟悉"基准"的新手，这是反直觉的。红绿颜色还会加重混乱：得分/扣分沿用"红涨绿跌"，**回撤扣分 −6.3 显示为绿色**，我第一眼以为扣分是好事。
- **建议**：成绩单里把"你赚了 x%，基准赚了 y%，所以你比基准少赚 z 点"放在最醒目位置（现在其实有，但被淹没在表格里）；扣分项用与"下跌"无关的警示色（比如统一的橙/红），不要和红涨绿跌混用；规则页的"基准"加一个小例子。

### 4.5 【中高】规则页的评分条是一整段话，数字密度太高；"最大回撤"依然没有解释
- **现象**：第一条"🎯 评分"约 250 字，含 5 组数字区间、3 种计分方式。我读了两遍才大致明白"三块分数 + B 过关"；"终局分每百分点 0.25（−20~60）"我完全不知道多少算好；"最大回撤"在这一条里直接被使用却没有定义（悬停说明里有，规则页里没有）。[规则页截图](ai-试玩截图-v0.3/g1-t01-rules.png)
- **影响**：规则页是一次性弹窗，读完就忘；我只记住"B 过关、回撤超 5% 扣分、跑赢基准加分"，其余靠边玩边看顶部。
- **建议**：把评分拆成 3 条短句 + 一个"典型一局大概拿多少分"的例子；规则页补"最大回撤 = 总资产从最高点回落的最大幅度"。

### 4.6 【中】开局即"预估等级 D"，以及"距下一等级"始终指向 C 而不是过关线 B
- 开局 0 分就是 D、"未到过关线 B"，有点打击。过关线是 B，但"距下一等级"写的是"距 C 还差 14.0 分"，真正想知道的是"距过关线还差多少"，需要自己用 29 减当前分。
- **建议**：可以同时显示"距过关线 B 还差 X 分"；开局给个中性文案（"本季度还没开始"）。

### 4.7 【中】单季度得分封顶/封底没有提示
- 第 1 局第 13 回合起本季度得分"+15.0"不再变化（已封顶）；第 2 局第 13–15 回合也是。我自己才意识到"再赚也没分了，只能防守"。界面只有数字，没有"已封顶"。成绩单里有"→ 触及上限 15"的标注，但顶部分数条没有。
- **建议**：顶部季度小格在触顶/触底时加小标记（▲/▼）和悬停说明。

### 4.8 【低】其他
- **第 1 周的回撤扣分太早、太重**（见 4.1），而且小结里提示得很清楚（"本周内总资产相对历史最高点最深回落到 9.5%"），问题是后果，不是信息。
- **顶部评分区信息量大**：总分、等级、本季度、距下一等级、等级尺、收益率、基准、全局超额、回撤、季度小格，全部在顶部。第一眼找不到重点，我是边玩边慢慢认出来的。
- **第 2 局的 −55 分在等级尺上被挤在最左端**，白线几乎贴在边缘，没有表达"比 D 区还差很多"。

## 5. 做得好的地方（值得保留）
- **构成表把算式写全**，触及上下限也标注——季度成绩单和结算页是整个评分里最清楚的部分。
- **等级尺 + 白色标记线**，一眼知道自己在哪个等级区。
- **回合小结里的回撤行**（"本周内最深回落到 x%；截至周末最大回撤 y%（超过 5% 开始扣分）"）解释了"为什么当前距高点和最大回撤不同"——这是上一轮的 4.8，现在好懂了。
- **错误提示贴在按钮下面**（第 1 局第 1 回合排第 4 笔订单被拒）：红色提示就在买入/卖出按钮下面，我立刻看到了。[截图](ai-试玩截图-v0.3/g1-t01-toast.png)
- **估值区间条**（金色段 + 白三角）：新手一眼看懂"现价在区间左边 = 偏便宜"。
- **新闻有了区分度**：例如"芯海科技公告签下常规供货订单，预计对当年业绩影响有限"，读完就知道不重要；以前的"具体金额未披露"做不到这一点。
- **季度制本身有帮助**：第 1 局第 12 回合，我在 Q2 得了 −4.0 之后，Q3 开局很顺（本季度很快 +13.5），"上个季度的坏成绩不会拖垮这个季度"让我重新有了动力（但回撤扣分会拖垮，见 4.1）。

## 6. 最严重的 5 个问题（汇总）
1. **回撤扣分权重过大且无下限**（4.1）：+64% 的收益拿 D，总分可到 −55；惩罚大盘下跌时的持仓与盘中回落。
2. **分数深度为负后"距下一等级还差 X 分"变成嘲讽，玩家自己判死并想弃局**（4.2）。
3. **C/D 时没有任何改进线索**（4.3）：结算只列分数，不指出最大丢分项，也没有反事实。
4. **相对基准的计分与绝对收益脱节**（4.4）：赚钱可以是负分、亏钱可以是正分；扣分项用绿色会被误读为好事。
5. **规则页评分段过长、数字密度高，且"最大回撤"没有定义；开局即 D 打击感强**（4.5、4.6）。
